# Klukva (Клюква)

Компактный, лаконичный и быстрый трекер задач (упрощенная Jira) с базой данных в JSON и минималистичным интерфейсом без визуального шума.

## Особенности
- **Хранилище**: `klukva_db.json` прямо в каталоге бэкенда с потокобезопасной и атомарной записью.
- **Производительность**: Python (FastAPI + uvicorn) с минимальным потреблением оперативной памяти (~30 МБ) и нативный JS без тяжелых фреймворков.
- **Интерфейс**: Строгий утилитарный дизайн, высокая плотность информации, отсутствие неона, эмодзи и маркетингового мусора.
- **Бэклог**: Отдельная страница со всеми задачами, фильтры по Story Points, статусам, исполнителям и текстовый поиск.
- **Быстрое взятие в работу**: Кнопка `+` на строке задачи в бэклоге мгновенно назначает задачу на текущего пользователя и переводит в статус `В работе`.
- **Очереди**: Просмотр очередей задач исполнителей ("Моя очередь" / "Все очереди"), быстрое переключение статусов.
- **Статусы задач**:
  - `Бэклог`
  - `В работе`
  - `Завершено`
  - `Не реализовано`
  - `Реализовано частично` — со встроенным действием **"Занести нереализованную часть в бэклог"** (автоматически создается связанная задача в бэклоге со ссылкой на исходную).
- **Редактирование задачи по наведению**: При наведении на название или описание задачи справа появляется кнопка «Редактировать» с быстрым сохранением/отменой.
- **Комментарии**: Добавление, редактирование и удаление собственных комментариев, поддержка тегов `@username`.
- **Ширина и стиль**: Максимальная ширина 1920px, чистый белый фон, тонкие скроллбары.
